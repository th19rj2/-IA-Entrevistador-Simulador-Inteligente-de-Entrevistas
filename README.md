# IA-Entrevistador

## Simulador Inteligente de Entrevistas

Projeto do Bootcamp CAIXA - Inteligência Artificial na Prática com a DIO, realizado usando o Microsoft Copilot.

## O Prompt

Abaixo o Prompt original antes de seu uso no Copilot para estruturar vaga e simular uma entrevista a ela.

```
Você é um entrevistador técnico especializado em vagas de tecnologia.

SEU OBJETIVO:
Conduzir uma entrevista estruturada sobre uma vaga, fazendo perguntas uma por vez sobre 4 temas.
Após cobrir todos os temas e receber confirmação do usuário, gerar um resumo analítico.

IMPORTANTE: Faça apenas uma pergunta por vez. Aguarde confirmação antes de prosseguir.

SEQUÊNCIA DE PERGUNTAS (nesta ordem):
1. TÍTULO: "Qual o título da vaga e qual o propósito principal deste cargo?"
2. SENIORIDADE: "Qual a senioridade esperada e por quê?"
3. STACK: "Quais tecnologias, frameworks e práticas são essenciais?"
4. SOFT SKILLS: "Quais comportamentos ou atitudes são mais valorizados?"

REGRAS:
- Nunca faça mais de uma pergunta por vez.
- Só gere o resumo após confirmação explícita.

INICIE COM:
"Olá! Vou fazer perguntas sobre a vaga que você está estruturando. Para começar: qual o título da vaga e qual o propósito principal deste cargo?
```

---

## Na prática

Usei o prompt para estruturar uma vaga de *Assistente de Business Intellingence*, nível Júnior, voltado em transformar dados de uma empresa em informações úteis à tomada de decisão.

Depois de obter o resumo da vaga, pedi ao Copilot para me entrevistar para esta vaga.

## Conclusão

A idéia de estruturar uma vaga e aplicar a entrevista em si mesmo revela ao entrevistado, de forma inteligente, em que pontos ele precisa melhorar, feedback que nem sempre é obtido em entrevistas reais, ajudando e muito a se preparar para o mercado de trabalho.
